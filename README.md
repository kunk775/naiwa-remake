# 勇者奶蛙传 · 复刻版

一个用原生 Canvas 手写的横版过关小游戏，单文件、零依赖、手机电脑都能玩。

**在线玩：** 打开 GitHub Pages 链接即可（点仓库右侧的 Environments / 或用 Pages 地址）。

## 玩法

奶蛙要闯过 7 关，从憋笑魔王手里救回豆公主。

| 按键 | 动作 |
| --- | --- |
| `A` / `D` 或 `←` `→` | 左右移动 |
| `空格` / `W` | 跳跃（带土狼时间与跳跃缓冲） |
| `J` | 肚皮冲撞：撞飞小怪、对 Boss 造成伤害，冲撞期间免疫接触伤害 |
| `K` | 大笑清场：震退周围小怪、清除飞行道具、硬直 Boss（冷却 6.5 秒） |
| `M` | 静音 / 恢复 |
| `R` | 重开 |

第 7 关是憋笑魔王，三阶段：跳跃砸地产生滚地波、召唤小怪、发射笑波。
最高分存在浏览器 localStorage。

## 关于声音

内置一段程序生成的循环配乐（138 BPM 卡通追逐风）。想换：

- 点击右下角 **「换 BGM」** 选择本地音频
- 或直接把音频文件拖进窗口

## 技术说明

- 单个 `index.html`，内联 CSS + JS，无构建、无依赖、无网络请求
- Canvas 2D 绘制，固定 1280×720 内部分辨率，按窗口等比缩放
- 程序化美术（没有使用任何第三方素材），音乐用 WebAudio 合成
- 支持键盘与鼠标/触屏点击开始

## 本地运行

直接双击 `index.html` 即可，不需要服务器（没有 ES Module、没有 fetch）。
